# Demo checklist

- [ ] Install module.
- [ ] Mark a safe test template as User Subscription Possible.
- [ ] Open test internal user.
- [ ] Confirm Notifications tab shows the subscribable template.
- [ ] Opt out.
- [ ] Confirm template Smart Button shows user.
- [ ] Confirm user Smart Button shows template.
- [ ] Send template.
- [ ] Verify opted-out user is excluded.
- [ ] Re-subscribe.
- [ ] Verify the user receives the template again.
- [ ] Demonstrate Chatter audit messages.
